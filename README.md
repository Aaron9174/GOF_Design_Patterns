# GOF_Design_Patterns

Practice different Gang of Four design patterns

# Adapter Design Pattern

The adapter design pattern is used to get two classes with incompatible interfaces to work together by wrapping its interface around that of the adapter class. The adapter class essentially acts as wrapper that conforms the classes public API to the desired interface.

# Factory Method

This design pattern utilizes object-oriented programming so that factory methods are used to simplify the creation of objects without having to specify their exact classes. Factory methods can be specified in an interface and implemented by subclasses or implemented in a base class class and overridden when needed.
